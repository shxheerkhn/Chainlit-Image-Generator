# AI Image Generator 🎨

Type a description of any image and **Pollinations AI** will generate it for you, right here in the chat. No API key required.

**Tips for better results**
- Be specific: style, subject, mood, lighting, colors
- e.g. *"a cozy cabin in a snowy forest at dusk, warm window light, oil painting style"*

Built with [Chainlit](https://docs.chainlit.io) + the [Pollinations Image API](https://github.com/pollinations/pollinations/blob/master/APIDOCS.md).
